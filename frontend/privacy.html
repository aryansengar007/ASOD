Privacy Policy

Last updated: 17 November 2026

This Privacy Policy explains how the Assignment Similarity and Overlap Detector (ASOD) handles documents submitted through its comparison interface.

1. Documents you upload

ASOD currently accepts TXT and DOCX documents. When you run a comparison, the selected files are transmitted to the ASOD application backend for text extraction and comparison.

2. Processing and storage

The current application implementation processes uploaded file contents in memory and does not implement persistent storage of uploaded documents or comparison results. Temporary processing occurs while the request is handled.

This statement describes the application code, not any additional infrastructure, hosting, reverse proxies, operating-system logs, or services that may be introduced when someone deploys or modifies the application.

3. Information collected

The current application does not implement user accounts, analytics, or third-party tracking integrations. The application processes document filenames and contents as needed to perform the requested comparison.

4. Your responsibilities

Only upload documents that you are authorized to use. Avoid submitting confidential, sensitive, or personal information unless you have appropriate permission and understand the environment in which ASOD is running.

5. Changes to this policy

This policy may be updated if application functionality, data handling, or deployment arrangements change.

6. Contact

ASOD is developed by Aryan Sengar. No dedicated support email address is currently provided through this application.
